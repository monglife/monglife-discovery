걸을수록 성장하는 나만의 펫

Mongs는 걸음 수로 펫을 키우는 다마고치 게임입니다. 일상 속 걷기를 미션과 보상으로 더 재미있게, 스마트워치 연동으로 더 정확하게 기록합니다.

  • • 스마트워치 생체 데이터를 서버와 실시간 동기화
  • • 배틀/훈련 활동과 보상
  • • 오프라인에서도 누락 없이 기록

주요 기능

걸음 기반 성장

걸음 수가 곧 포인트! 경험치를 쌓아 레벨을 올릴수록 몽이 새 모습으로 성장합니다.

스마트워치 연동

Wear OS / 기타 워치와 연동하여 더 정확한 활동 데이터를 수집합니다.

오프라인 대응

네트워크가 불안정해도 데이터 손실 없이 안전하게 동기화됩니다.

보상

배틀/훈련으로 작은 성취를 쌓고, 보상으로 꾸준함을 유지하세요.

인벤토리 & 간식

뽑기로 모은 아이템을 인벤토리에 보관하고, 간식으로 몽스를 돌봐요.

개인정보 보호

자주 묻는 질문

스마트워치가 꼭 필요한가요?

네. 현재 게임 플레이는 워치에서만 가능합니다.

오프라인에서 걸으면 기록이 누락되지 않나요?

네트워크 복구 시 안전하게 동기화되도록 설계되어 누락을 최소화합니다.

수익화 방식은 무엇인가요?

현재 수익화 보다는 사용자에게 좋은 경험을 제공하는 것이 우선이라 무료로 플레이가 가능하고, 인앱 결제 및 포인트 보상형 광고를 도입 예정에 있습니다.
